# Ash 🤖

An AI-powered personal operating system. Send natural language commands 
from your phone or web app — Ash executes them on your server.

## Stack
- **Backend:** Django + Django REST Framework
- **Agent:** Python + Groq (Llama 3.3) / Claude API
- **Queue:** Celery + Redis
- **Database:** PostgreSQL
- **Client:** React (web) + Flutter (mobile)
- **Deployment:** Ubuntu VPS + Nginx + systemd
